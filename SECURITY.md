# Security Policy

Please report suspected security problems privately to [info@parakeet.se](mailto:info@parakeet.se). Do not report them in public issues.

When reporting a problem, include:

- The affected repository or component
- Steps to reproduce the problem
- Its possible impact

The software controls vehicles, so reports involving flight safety, command authentication, or radio links are especially welcome. Reports will be acknowledged; no specific response time is promised.
