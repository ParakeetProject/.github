# Parakeet

**Drones find. Rovers fetch.**

Parakeet is software that lets a small team of drones and ground rovers search an area together and keep working safely when the radio link drops. The project is focused first on search and rescue, with inspection and clean-up work as later goals. It is an early-stage civilian project; nothing is available to buy or use yet.

## Where we are

Simulation is ongoing, and the team is developing and test-flying its first drone. Devlogs will be posted on the [website](https://parakeet.se) as the project moves forward.

## What you'll find here

Selected parts are published here so the software and project decisions can be traced. Parakeet is not open source.
